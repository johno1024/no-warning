# NO WARNING — The Chemistry Test

A mobile-first two-person chemistry-test experience inspired by the NO WARNING card game.

## Current preview

This repository currently contains the static interactive preview used to test the complete 40-question UI and reveal experience. The five PLAY IT OUT challenges are intentionally fixed rather than randomized.

### Preview flow

1. Enter a name/nickname.
2. Complete all 40 questions.
3. Lock the answers.
4. Simulate Player 2 completing their test.
5. Reveal the chemistry results.
6. Complete the five static PLAY IT OUT challenges.

The production Share Link / Reveal Link backend can be added separately without changing the question UI.
